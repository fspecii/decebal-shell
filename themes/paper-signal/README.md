# Paper Signal

A slim flat panel, precise rectangular windows and quiet editorial typography.

Select any named color palette independently. This package controls desktop structure and provides complete light/dark token defaults; it does not force wallpaper color matching. Shared builtin widgets remain available on every theme, with global enable/disable choices preserved by the shell. Manifest widget entries are initial placement suggestions.

Fonts fall back to Inter/Noto Sans or DejaVu Sans Mono if the preferred families
are unavailable. The former SVG wallpaper masters and PNG artwork are removed.
See `docs/theme-research-glass-paper.md` for historical design research; its old
wallpaper experiments are not current package defaults.

## Wallpaper choices

Open **Wallpaper → For this theme** and select the separately curated Wallhaven
photograph: dark [eyv7xl](https://wallhaven.cc/w/eyv7xl), light
[x83e2z](https://wallhaven.cc/w/x83e2z). The source catalogue at
`data/wallhaven-curated.json` records uploader versus unverified author, unknown
license, source links and crop/readability notes. These links are recommendations,
not package-owned remote fields or a redistribution license.

This package sets no wallpaper image, scaling mode, background colour, slideshow
or download action. Theme apply and mode changes preserve the independent
Wallpaper selection; no automatic downloads or generated artwork fallback.
Former generated artwork and packaged screenshots containing it were removed.
The palette, layout, captions and native widget definitions remain unchanged.
