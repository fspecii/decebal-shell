# Everforest compatibility package

This hidden legacy package remains loadable for compatibility; its colour alias
is available through Palettes rather than a new visible theme/catalogue entry.
Generated wallpaper and screenshots containing it have been retired.

No palette, font, caption, bar/dock geometry or widget source is changed.

The manifest declares no wallpaper image, scaling mode, background colour,
slideshow or download action. Wallpaper selection is independent. Choose your
photo explicitly in Wallpaper settings; no automatic downloads, generated fallback
or new recommendation ID is introduced for this hidden alias.

Original package metadata/license remain intact. No new photo is bundled or
relicensed. See `docs/hidden-wallpaper-removal.md` and the exact removal hashes in
`docs/generated-wallpaper-removal.json` in the source repository.
