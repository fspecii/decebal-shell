# moss-atlas: original vector artwork

These two SVG masters were drawn for Decebal. They contain no external images, scripts, fonts or references.
The engine accepts PNG/JPEG/WebP package assets, so the reproducible vector source is retained here and rendered to the adjacent PNG files.

Render a fenced master with `rsvg-convert --output wallpapers/moss-atlas-dark.png master.svg`.
