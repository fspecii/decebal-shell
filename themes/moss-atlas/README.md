# Moss Atlas

An organic workspace with a right-hand instrument rail, generous rounded surfaces and organic spacing. Design stays constant when the palette changes.

The theme defines geometry, typography and layout. All shell surfaces and shared widgets use semantic theme tokens; selecting another palette keeps this design intact. The included dark and light colors are defaults, not requirements. Font family lists fall back to installed Noto or generic families; no proprietary fonts are bundled.

The former vector wallpaper artwork, SVG masters and packaged screenshots are
removed. Photographic wallpaper is now selected separately.

Three shared built-in widgets provide clock, monitoring and media controls, with breathing room for windows. Placements are initial defaults; global widget preferences remain the user's choice across theme changes. No widget implementation belongs to this theme. The shell controls actual bar thickness; this package uses only supported bar placement and geometry.

Inspired by the composition and restraint documented in `docs/theme-research-organic-retro.md`, without copying third-party artwork. Package configuration remains MIT licensed; no external photograph is relicensed.

## Wallpaper choices

Open **Wallpaper → For this theme** and select the separately curated Wallhaven
photograph: dark [vqxkr5](https://wallhaven.cc/w/vqxkr5), light
[768yeo](https://wallhaven.cc/w/768yeo). The source catalogue at
`data/wallhaven-curated.json` records uploader versus unverified author, unknown
license, source links and crop/readability notes. These links are recommendations,
not package-owned remote fields or a redistribution license.

This package sets no wallpaper image, scaling mode, background colour, slideshow
or download action. Theme apply and mode changes preserve the independent
Wallpaper selection; no automatic downloads or generated artwork fallback.
Former generated artwork and packaged screenshots containing it were removed.
The palette, layout, captions and native widget definitions remain unchanged.
