# Palette mapping (UKUI tokens to Decebal roles)

Generated by `assets/desktop-ports/openkylin/tools/build_packages.py` from `derived/tokens-<theme>-<mode>.json`
(resolved `ukui-globaltheme` CSS tables, commit 83cb8ff). Decebal colours are opaque `#rrggbb`, so every UKUI alpha token is
composited over the role's own backdrop (`window-active`). Rules, in the order they apply:

| Decebal role | UKUI token | Rule |
|---|---|---|
| `background`, `bar`, `dock`, `titlebar` | `window-active` | as is (UKUI panels and titlebars are the window colour, translucent over blur: `bar_alpha`/`dock_alpha` = `transparencyBlur`) |
| `titlebar_inactive` | `window-inactive` | as is |
| `surface` | `base-active` | content/base area |
| `sidebar` | light `kgray-3`; dark `kcontain-secondary-normal` over window | |
| `popup`, `overlay` | `kmenu` over window | v11 menus are 78 % (light) / 82 % (dark) translucent: `popup_alpha` 0.82; the other three themes' menus are opaque |
| `border` | `kdivider` over window | |
| `text`, `bar_text` | `kfont-primary` over window | |
| `text_secondary` | `kfont-secondary` over window | nudged towards `text` only as far as needed to reach 4.5:1 |
| `text_faint` | `kfont-secondary` over window | nudged towards `text` to reach 3:1 |
| `accent` | `kbrand-normal` (v11 `#3676F5`, HeYin `#8926EB`) or `kbrand1` for Classic | Classic's own highlight is a 70 % white (light) / 40 % black (dark) wash of `#3790FA`; as an accent for text and thin lines that wash is unreadable, so Classic uses the solid brand colour (documented difference) |
| `accent_text` | `highlightedtext-active` | replaced by white/black, whichever contrasts more, if the source text would fall below 3:1 (Light-Seeking dark) or for Classic's flat accent |
| `danger`, `ok`, `warn` | `kerror-normal`, `ksuccess-normal`, `kwarning-normal` | solid base colour (Classic: the base under its wash) |

Radii, shadows, fonts and translucency come from `theme.conf` and the same tables: window radius 12 (Classic 0), menu 8,
normal 6, min 4; font `Noto Sans CJK SC` 14/22; animation 150 ms; blur/opaque alpha 65/90 (HeYin 75/90).
